{# The refill indicator: one line saying what the background thread is doing. It is rendered on every state of the batch page, and base.css hides it behind a batch only while it has nothing to report: "Pool 0 of 500, refill not running" is the whole diagnosis, and without it an empty page and a dead thread look exactly alike. A plain line and not a poll: the numbers move slowly, the page is reloaded often, and htmx polling this would be a request a second for something nobody is watching. The last run says which of the two strategies made it, because a pool that only ever grows at random has no favourites or likes in the decision log yet, and the reader can do something about that. How much of the pool is lookalikes says whether that search is feeding it, so a stocked pool says so even when it is none. #}
