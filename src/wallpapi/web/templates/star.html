{# The star: **Favourite** on a tile, the same on every page that has tiles. A macro rather than a partial because the request is the page's own: the caller writes the htmx attributes of its post between `{% call star(...) %}` and `{% endcall %}`, and the star adds the look, the words and the F key. {% from "star.html" import star %} {% call star(starred) %}hx-post="..." hx-vals='...' hx-target="..."{% endcall %} The star must be a direct child of its tile, which is how it finds the tile it belongs to; its look is `.star` in base.css. `starred` is what the server holds: the star shows it as `aria-pressed`, and the caller's post says what a click should leave, so a starred star posts the clear. F stars the tile with keyboard focus, or else the one under the pointer, as an htmx trigger on the body: each star asks whether the key is for its own tile, so no script decides it. Never while typing in a field, with a modifier held (Ctrl+F is the browser's find), or as a held key repeats. The child combinator is written `>` so that nothing reading the tag stops at it; the browser decodes it. #} {% macro star(starred) -%} {%- set f_pressed -%} click, keydown[(key == 'f' || key == 'F') && !repeat && !ctrlKey && !metaKey && !altKey && !target.closest('input, select, textarea') && (this.parentElement.matches(':has(:focus-visible)') || (!document.querySelector(':has(> .star):has(:focus-visible)') && this.parentElement.matches(':hover')))] from:body {%- endset -%} {%- endmacro %}
