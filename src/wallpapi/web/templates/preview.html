{# The preview: a Pico modal over the **Batch**, opened by clicking a tile's thumbnail. One dialog for the whole page rather than one per tile: only one **Wallpaper** is ever being looked at. It sits outside `main` and outside anything htmx swaps, so the Alpine component on it lives as long as the page does and a tile swap underneath cannot take it away. **The image carries no source in the markup, and never gets one by binding.** `open` sets it by hand when a thumbnail is clicked and `closed` removes it again, so the full-resolution file is fetched from Wallhaven only when somebody asks to see it and a dismissed preview stops downloading (ADR 0003). The tile carries the URLs as data attributes, which cost nothing until read. A click on anything that is not a control dismisses it: the overlay round the article, the image, the bare header and footer. Escape does the same natively. In fullscreen a click on the image leaves fullscreen instead, since the dialog is no longer what is on screen. The footer is the preview's own **Verdict** rail, below the image where it covers nothing. It posts nothing of its own: it clicks the matching control on the tile behind, so there is one route, one swap and one marked state. After any swap the rail reads the tile's mark back, which is how the ring and the rail agree. Marking does not dismiss the preview. #}
